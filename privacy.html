Privacy information for VPS Backup rclone

Last updated: 11 November 2026.

VPS Backup rclone is a personal backup configuration operated by Camillo Tellefsen. It connects to the owner's Google Drive account using Google's OAuth authorization.

Access and purpose

The requested Google Drive permission allows access to files in the authorized account. It is broader than access to a single folder. The backup configuration uses that permission to read file and folder metadata, upload backup files, verify stored files and download backups for restoration from the configured backup locations.

Google account information is used to check that the backup tool is connected to the intended account. Authorization credentials are stored in private configuration files on the operator's server.

Storage and control

Backup files are stored on the operator's infrastructure and in the authorized Google Drive account. Retention is controlled by the operator's backup configuration. Revoking the app's access does not itself delete existing backup files.

The account owner can revoke access through Google Account connections. Backup files can be managed in Google Drive.
